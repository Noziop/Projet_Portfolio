# Deployment Instruction

## Clone this Repo !

First, you'll need to clone the repo and navigate to stellar-sutdio dir :

```bash
git clone https://github.com/Noziop/Projet_Portfolio.git && cd stellar-studio
```

## Engines ready ? countdown at 0 ?

then you'll have to start the containers (make sure Docker's installed in your environment)

```bash
docker-compose up -d
```

Make yourself comfortable, the original build can take up to 30mins.

## Containers are build and up ?

simply navigate with your prefered browser to : 

```
http://localhost:8080
```
